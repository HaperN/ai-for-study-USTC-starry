# 离线三维图解

运行 `python tools/build_practice_spatial.py examples/practice_spatial/offline`，随后直接打开 `offline/三维图解.html`。无服务器、网络与构建器依赖；Three.js r137 和 KaTeX 来自仓库现有 vendor。

交付集成调用 `build_spatial(out, bindings)`。`bindings` 的两个可选键是 `sphere` 与 `log`，各自接收关联题目的 ID 数组；页脚跳往同目录的 `完整版-习题集.html#practice-ID`。函数只写新页面、独立命名的三维资源和本地公式依赖，不改正文数据、旧播放器或批注。

独立入口使用 `三维图解.html#sphere` / `#log` 或 `?scene=sphere` / `?scene=log`，仅初始化选定场景。答案内建议 `三维图解.html?scene=sphere&embed=1`；`embed=1` 去掉页头导航，返回题目的链接使用顶层窗口。hash 切换会销毁旧场景；节点卸载也会释放渲染器。静态后备路径分别是 `assets/practice-spatial-sphere.svg`、`assets/practice-spatial-log.svg`。

## 为什么需要三维与动画

- 黎曼球面：采用教材 CH01-S01-SS05 的球心 `(0,0,1)`、半径 1、北极 `(0,0,2)` 与南极切平面模型。平面点、北极投影线和球面交点要同时存在于空间。旋转消除投影重叠；播放明确展示有限模增大时球面点趋近北极。图中参数限定为有限的 `0 ≤ r ≤ 12`，只有独立北极标记表示无穷远点。
- 复对数：固定模绕原点一圈后，输入回到同一点而连续辐角增加 `2π`。螺旋曲面展示的是 `(Re z, Im z, 连续辐角)`；`Re w = ln r` 放在读数中，未声称三维图表示完整的四维复值图像。

对数解析主支采用 `−π < Arg z < π`、定义域 `C \ (−∞, 0]`。负实轴处主支读数明确为未定义；连续路径提升的对数值依然存在。页面说明负实轴主值约定与解析域的区别。θ 滑块以 π 为单位，因此能准确选中负实轴。图上只绘制 `0.3 ≤ r ≤ 2.4`、`−2π ≤ θ ≤ 4π`；数学上连续 θ 可以取任意实数，三层显示不意味着只有三个对数值。

## 数学依据

令 `d = r² + 4 = x² + y² + 4`。教材模型中的球面点为 `(4x/d, 4y/d, 2r²/d)`。其坐标满足 `ξ² + η² + (ζ−1)² = 1`；与北极之差为 `(4/d)(x, y, −2)`，因此与平面输入 P 和北极 N 共线。因为 `0 < 4/d ≤ 1`，Q 始终在完整 N→P 线段上，`r < 2` 时也无需延长到 P 外。到北极的距离为 `4/√d`，任意有限参数均大于零。

逆投影是 `z = 2ξ/(2−ζ) + i·2η/(2−ζ)`，只在 Q ≠ N 时使用。`|z|=2` 时 `ζ=1`，恰为赤道；`z=0` 对应南极 `(0,0,0)`。该公式不能与球心原点、北极高度 1 的另一常用模型混用。

方形平面窗口为 `[-2.6,2.6]²`，是否超出分别按 `|x|>2.6` 或 `|y|>2.6` 判断；不能仅用模 `r>2.6` 代替。

对数曲面的参数为 `(r cos θ, r sin θ, θ)`。θ 增加 `2π` 保持前两个坐标，且虚部增加 `2π`；实部 `ln r` 不变。为便于同时展示三层曲面，竖向绘制使用 0.36 的比例，轴刻度和所有读数仍显示原始 θ。底面是输入平面的辅助显示位置，不是第三个函数值坐标。
