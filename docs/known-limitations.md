# 当前版本的限制

本页描述 2026-11-20 的公开预览版本。

- 课程成品为复变函数 A。76 个教学单元及现成媒体是经过持续编辑的交付，不能据此宣称任意 PDF 都能自动生成同等质量内容。
- 仍有 75 项既有数学内容待核对记录。本轮工程整合没有批量改写这些内容，也没有给整本教材做数学认证。
- 视频音轨可完整转写，视觉分析使用定时及画面变化抽取的帧。抽样分析不能等同逐帧审查；识别、公式及模型生成仍可能有误。
- 视频解析入口处理本地文件，不会自动下载任意网站链接。仓库没有附带原始课堂录像、识别模型权重或作者账户。
- 共享感悟在进入小节或手动刷新时更新，没有自动实时推送。没有真实学校统一认证。
- 本地服务不等于公网网站。制作工作台与阅读服务分开运行，不能直接把本机管理接口当作公共站点。
- 私人笔记导入会保留冲突副本，超大型笔记库的导入性能尚未压测。
- 当前验证主要在 macOS 与 Edge/Chromium 环境完成。不同浏览器、系统、字体和媒体解码器的兼容性仍需核对。
- “课程如星星”的知识星空为后续界面设计方向，本次没有交付星图式科目首页。
- 历史测试依赖部分未分发的数据、旧环境或本机工具；公开仓库不承诺完整历史测试库在任意空机器上一键全绿。
