# 昵称共享感悟（本地第一版）

现有教材页面增加“同学感悟”。填写昵称即可发布公开文字，不需要注册、密码或模型服务。打开小节或点击“刷新”读取新感悟，不使用实时弹幕。

## 启动

从项目源码目录，使用 Python 3.12 环境执行模块入口 aiforstudy 的 community 子命令。参数如下：

- --reader：已有交付中的 book 目录，须含 index.html 与 data/data.js。
- --database：用于持久保存感悟的 SQLite 文件，必须在教材目录之外。
- --port：默认 8791；0 表示系统选择一个空闲端口。通常保持固定端口，方便浏览器保留作者身份。

完整命令形状：PYTHONPATH=src python -m aiforstudy community --reader /path/to/delivery/book --database /path/to/data/annotations.sqlite3 --port 8791。

启动会输出本地 URL。程序只监听 127.0.0.1。浏览器打开该 URL，不要双击教材 HTML；直接打开文件时不会挂载共享服务。只运行此子命令无需启动生产控制台、下载模型或调用 AI。

## 使用

1. 打开“同学感悟”，正文旁显示“写感悟”；已经有感悟的位置平时也显示数量。
2. 点击段落、公式或图像旁的入口，核对面板中的原文，填写昵称和感悟，点击发布。
3. 其他浏览器打开同一版本、同一小节，或点击刷新，即可读取。每页最多 50 条，可加载更多。
4. 本浏览器发布的感悟显示“删除”，再次确认后删除。昵称相同的其他浏览器不会获得删除权限。

昵称用于显示，允许重名，不代表认证身份。浏览器保存一份随机作者凭证；数据库只存摘要。清除浏览器数据、换设备、换网站域名/端口后，原凭证不会自动迁移，因此不能直接删除以前的感悟。浏览器禁止保存数据时仍可阅读，但不能发布。私人笔记使用原先的 IndexedDB，始终不会自动转成公开感悟。

## 内容与版本

只接收纯文本：昵称 1–30 字，感悟 1–2000 字。公式定位从原 LaTeX 生成，不使用重复的屏幕排版字符。针对图像的感悟绑定整幅图；这版不冻结动态图当前参数或视频时刻。重复段落按单元、所属字段、文字和出现序号区分。

读本 data.js 的 SHA-256 构成版本身份。换了该文件，即使只修改了内嵌音频，也会形成新版本；旧感悟仍在数据库，不会自动挂到新版。运行中检测到数据文件变化会停止读写，要求重启。旧页面向重启后的新版本提交也会被拒绝。

## 数据保全

数据库在 --database 指定的位置；停止服务后备份该文件即可。服务运行时 SQLite 可能使用 -wal/-shm 辅助文件，应先停止服务或用 SQLite backup 工具再复制。源码和教材成品没有承载感悟数据；不能只备份 HTML。

## 部署边界

这是可运行的本地共享功能，不是已经发布的公网网站。以后接入现有服务器时，应保留相同接口与 SQLite 数据，结合对方的 HTTPS、域名、反向代理、进程管理、备份和公共内容管理方式配置。当前服务明确只接受回环 Host/Origin，不能只把端口映射出去就称已上线；不要改成对外开放现有生成控制台。

当前限制为每作者每分钟 20 条新感悟，以及连接来源每分钟 60 次写请求。这些限制面向本地试用，不声明防机器人注册或大规模抗滥用能力。昵称模式也不能核验真实学生身份。

## 本轮验证

- SQLite 跨实例持久化、作者删除隔离、书/版本/单元隔离、幂等发布、边界值和速率限制。
- 真实 HTTP 两客户端、服务重启、跨站/Host 拒绝、旧页面版本拒绝、路径与符号链接封闭、媒体 Range。
- DOM 公式与重复段落定位、媒体布局变化、晚到请求不串节、失败保留草稿、提交期间的新草稿不被清空、文本注入防护。
- 两个独立浏览器上下文完成发布、查看、同昵称删除拒绝、重启后读取和作者删除。
- 真实复变教材的浏览器检查结果另存于本轮验收记录；不把窄屏桌面浏览器检查称为手机真机验收。

## 学校身份认证扩展接口

现阶段默认仍为 NicknameIdentityProvider，不启用登录。学校认证只预留接口，没有猜测学校的 CAS、OIDC、SAML 或统一认证地址，也没有连接真实学校系统。

后端接口位于 src/aiforstudy/community/identity.py：

- IdentityProvider.resolve(headers, required=False)：由适配器验证学校会话或凭证，返回 Principal，未登录的只读请求可返回 None，需要写入却未认证时抛 IdentityError(401, 提示)。
- Principal(namespace, subject, display_name=None)：namespace 是学校/身份源的固定命名空间，subject 是认证服务确认的稳定用户 ID；不能使用昵称、邮箱显示名或请求正文中的 user_id 作为身份。display_name 可选，有值时覆盖客户端提交的作者显示名；当前长度限制为 1–30 字。
- make_server(reader_dir, database, port=8791, identity_provider=适配器)：接入点。现有 CLI 不传适配器，因此继续使用昵称模式。
- GET /api/identity：返回 mode、authenticated、display_name、can_publish、login_path。不会返回学号、稳定 subject、凭证或数据库身份摘要。login_path 由未来适配器提供，实际登录/回调路由需随学校协议实现。

身份适配器运行在服务端。服务器不会因为请求带 X-School-User、user_id、subject 或某个昵称就承认学校身份。学校模式使用同源会话，不要求匿名浏览器凭证；当前前端预留 identity_mode/identity_api 配置，后续登录界面可以使用身份查询接口。

同一个 namespace/subject 在不同浏览器产生相同的批注归属键；改显示名不改变归属。不同学校的相同 subject 不会混在一起。当前昵称记录的归属键保持兼容。

启用学校认证不会自动认领既有匿名感悟。若以后需要迁移，必须由用户证明持有旧浏览器凭证并通过学校认证，另做明确认领流程；不能按相同昵称自动合并。

配置学校适配器后，前端会先读取身份接口；学校提供显示名时，在发布前显示实际公开署名并锁定该字段。身份暂不可确认时不退回昵称写入。学校显示名更新不改变稳定 subject，也不会让同一请求的重试重复创建感悟。

## 图片批注扩展

现在支持选择/粘贴图片，并按每张图片选择直接呈现或本地识别后呈现。纯图片可以直接发布，不再要求同时输入文字。详情、限制和OCR运行参数见 docs/image-annotations.md。学校身份接口保持不变。
