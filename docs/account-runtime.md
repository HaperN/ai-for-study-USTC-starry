# 模型服务配置

公开的 `config/models.json` 是占位模板，默认不会借用已登录的作者账户。服务地址使用 example.invalid，密钥只通过 `env:STARRY_MODEL_API_KEY` 显式读取。离线阅读与共享批注不需要模型密钥。

要运行新生成任务，维护者需要设置实际支持的 provider、base_url、每个角色的模型名、思考参数与输出上限。应以所选服务实际支持的参数为准。模板中的额度只用于说明配置结构，不代表任何模型的能力承诺。

支持的路由：

- `deepseek`：既有 HTTP 适配器。配置实际 endpoint 与显式密钥引用；服务必须兼容该适配器的请求协议。
- `local-compatible`：显式本地兼容服务，必须填写 base_url 和模型名称；匿名访问默认只接受 loopback。
- `deepseek-account`：可选的 macOS Harness 账户 SDK 桥接，需要使用者本机支持的安装与登录。本公开配置未启用它；它不表示仓库附赠账户或 API 额度。

`.env.example` 是参考文件，程序不会自动加载它。请通过 shell 环境变量传入自己的凭据；不要把值写进源码、截图或提交记录。角色也可以分别配置路由。账户桥与 HTTP 端点不是可随意互换的接口。

启动工作台、查看页面和配置预检不等于发送生成任务。真实生成可能调用外部服务并产生费用；请先用自己的小型材料确认来源和参数。历史预算测试工具不代表生产程序具有完整费用上限。

Manim、TTS、ASR、OCR 和浏览器等使用本机依赖，见相应模块指南。这里没有作者机器路径、模型权重或登录信息。
