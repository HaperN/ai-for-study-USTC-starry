# 复变函数 A 本机整合版

双击「启动整合版.command」。终端显示两个本机地址后，浏览器会打开学习首页。默认学习端口 8792，制作工作台端口 18917。终端按 Ctrl+C 可关闭本次服务。端口被占用时可修改 config.json。运行 `./启动整合版.command --check` 可检查配置；运行 `./启动整合版.command --no-open` 可自行打开终端给出的地址。

教材有 76 个教学单元，基础版有 42 道题，完整版有 103 道题。动画目录收录 12 段教材动画和 3 段习题动画；保留原有打印 PDF。离线转发请使用单独的「同学阅读包」，整合版中含本机路径与私人数据库快照。

共享感悟使用原有 A 库的备份，新服务写入「批注/notes.sqlite3」。A.sqlite3 与 B.sqlite3 为独立快照。B 的身份体系不同，昵称不能证明所有权。两库本次快照均无已发布感悟。私人笔记与浏览器、地址及教材版本相关。请在原地址导出，再在新地址导入并核对；保留原备份。同一编号的笔记如果内容不同，本地笔记保留，导入的那条标为“备份副本”，并保留原教材版本和位置。再次导入相同内容会自动跳过。原来的 8791 和 18916 服务可继续使用。

练习制作修复了分级覆盖、证据文件重名、媒体题误判和重试预算问题。视频引擎可在核对身份与摘要后恢复已完成的生成结果，保留引文并核验待发布修订。工作台初始书目为空。共享批注支持作者修改、并发版本核对、回到原文和图片。教材发布和回滚增加了文件完整性与章节指针检查。

当前服务依赖本机 Python 3.12 虚拟环境、Node 与本机工具路径。配置中的图片识别模型仅在用户发起时调用。验证采用离线替身；本次打包没有重新生成模型、语音或动画。早期 Task 2 测试曾意外尝试 3 次真实账户桥接，后续验证使用离线隔离。旧全量测试有已记录的环境及历史失败；本次核验覆盖受影响的子系统。另列的 75 项教材内容问题仍待逐条校订。

release.json 记录代码和教材版本、输入与批注行数；sha256.json、student-sha256.json 分别记录两个目录的交付时摘要。运行服务后活动数据库和工作区会变化。source.zip 与 source/ 是同一提交中的程序。重建使用对应提交的 Git 检出，具体命令见 source/docs/integrated-study.md。

本机候选版已在 Edge 中通过离线与临时端口验收。离线检查涵盖 400 个页面及样式链接、103 道题在 27 个单元中的挂载、动画和用途配音播放；375 份媒体、字体与 PDF 与正式输入逐字节一致。临时端口检查使用数据库副本，走通练习回到教材、原卷打开、作者发布与编辑、查看原文和删除。受影响的合并测试初次为 Python 668 通过、30 失败、2 跳过、5 排除，Node 为 69 通过、3 失败。补上旧测试使用的浏览器与解释器环境变量后，仅重跑这 30 项和 3 项，全部通过。5 项历史排除涉及旧图版本、MinerU 测试输入、schemdraw 依赖及超时预算。结果不代表全书数学内容或全部历史测试已获认证。
