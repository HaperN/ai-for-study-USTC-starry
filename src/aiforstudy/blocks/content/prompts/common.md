自测的每个 misconception_feedback.id 都须有至少一条 test_cases 实际评分为 incorrect 且反馈命中该 ID；建议在用例 feedback 中写明预期分支 ID。不能只满足 correct/wrong/boundary 三种 coverage 就省略其他错因的用例。新增普通错误用例使用 coverage=wrong；真实错误的边界用例仍可使用 coverage=boundary。评分器按分支顺序匹配，同一个输入被更早分支命中时不算覆盖后面的分支。

首次定理使用既有 explainables 的 kind=theorem、concept_id 和完整讲解字段，通过单独一段 EXPLAIN 标记在主线完整内嵌；条件、结论与直观解释可见，所有证明默认折叠、点击展开，也无需 body_markdown 再复制。后续正文与生成例题按真实 C-ID 用 CONCEPT 原地复用，所提供完整例题的推导仍须完整。名称优先正式名，否则准确描述性名，不冒充公认名；原编号保留于来源目录与原书资料，不按同名或同编号合并。available_theorem_names 只列前文定理名称，不附带其讲解或证明；根据数学知识核对当前用法，不能假称读过未提供的前文。现有审核核对当前正文所提供的证明、适用条件和来源对应，不要求补交前文证明，不增加审核项目或数量门槛。

审核者的本次任务范围只取 frozen_context.criteria 数组，逐项复制其中的 criterion_id 与 version。宿主会分批调用以覆盖全部标准；candidate_content、machine_findings、math_findings 和 previous_tickets 用于理解证据，不是本批新增审核项目。不要因其中出现其他 criterion_id 而返回上一批或其他批的项目，也不要跳过本批项目。
教学质量结合完整候选判断：允许复用正文和相邻讲解中已经讲清的材料，不要求每张概念卡重复全文。实例、反例、类比和易混项对照按实际理解困难选用；不按固定配套数量或格式偏好判 fail；独立补充和就地短链接按当前阅读规则核对，缺失时说明具体条件、推理或阅读缺口如何妨碍理解。

审核范围以当前用户口径为准：定义和概念未附证明或非必需拓展不构成 fail/unknown；当前必要讲解和阅读组织仍须核对，也不能通过目标措辞、来源忠实或概念解析规则间接要求补证明。例如说明复数不能像实数一样按与加法、乘法相容的方式比较大小，条件与含义正确即可，不强制证明；所提供的证明和完整例题仍须逐步完整推导，不能改称概念来规避。

教学证据绑定只帮助定位。缺少 claim 与来源义务、goal 与读者文字或理解任务的绑定，只作提示，不代表正文未讲、缺少推导或缺少自测；审核必须阅读完整 candidate_content 的正文、例题全部步骤及自测，不能仅因漏绑而判 fail 或 unknown。absence 类型仅表示宿主没有找到绑定，不是正文缺失的事实。reader/source 类型证据 ID 均可选，evidence_refs 允许为空；不要为了凑齐证据类型编造 ID 或要求作者重写已有正确正文。
审核判 fail 时，在现有 reason 内写清具体位置（章节、例题第几步或现有字段路径）、错误原句或公式、错误原因和修改要求，不新增字段或报告。若是实际缺少内容或推导步骤，指出应出现的位置和前后已有句子或公式，说明具体缺哪一步及应补什么，不编造不存在的原句。知识错误、必要条件遗漏、定理和例题推导缺步、自测评分错误仍须明确判 fail；实际无法判断才判 unknown。通过也须结合实际正文说明理由，不能只凭有 ID、内部计划或 CAS 状态宣布正文正确。

显示折叠不等于删减教学内容：提供的定理、性质、推论及正文夹带的证明默认收起，条件、结论和直观解释仍可见；提供的每道完整例题的题干、思路、全部步骤、依据和答案整体默认收起，只显示标题入口，点击后完整读取。生成仍保存所有字段和原件。证明优先放已有 theorem steps/markdown；正文确需补充证明时以独立“证明：”段开头、以“证毕。”结束，下一概念或直观解释另起段，便于确定边界。审核必须读取全部折叠内容，不能因默认收起要求删除证明、展开首次证明或降低完整性要求。
