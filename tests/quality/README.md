# 离线质量行为对照

`manifest.json` 固定 6 个真实单元和 28 个受控样本。`controlled_cases.py` 将样本连接到当前生产函数；`run_benchmark.py` 运行实际逻辑并生成逐例证据。引用摘录差异样本按现行规则不再要求机器逐字匹配拒收；这只验证宿主行为，不证明摘录内容正确。错误证据 ID 与模型明确报告的实质错误仍有独立回归。

```sh
PYTHONPATH=src ../.venv-linux/bin/python tests/quality/run_benchmark.py
```

默认输出至项目文档中的 `教学质量内核重构-20261008/Q11-离线质量对照.{json,md}`，可用 `--output-dir` 改变位置。退出码非零意味着至少一例不匹配、执行出错、未决或尚未绑定。

这里的 28 例只衡量程序门禁对已知受控输入的表现。固定审核输运不是独立模型或教师评阅，批准接口接收它只说明契约链工作，不代表真实教学质量。此执行器不读真实书籍或保留单元，不调用付费 API，不执行完整流水线或 Manim 视频，真实单元与人工评阅状态仍待独立验收。
